# Painel AI Champions

Painel para cadastro, gestão e priorização de iniciativas de IA do programa Champions.

## Objetivo
Centralizar iniciativas, apoiar tomada de decisão e dar visibilidade para líderes e creators.

## Funcionalidades
- Cadastro de iniciativas
- Priorização (GUT + Complexidade)
- Kanban por quarter
- Dashboard executivo
